# Sky’s Ley Lines 0.5.3.121012 beta

This build adds a documentation index and expanded player, operator, and integration guides inside the mod JAR. Open `META-INF/skysleylines/docs/README.md` for the complete map.

| Component | Compatibility |
| --- | --- |
| Minecraft | 1.21.1 |
| NeoForge | 21.1.247 or later in the 21.1 line |
| Java | 21 |
| Mod ID | `skysleylines` |
| Java API | 2 |
| Ley layout | 1 |
| Save schemas | Reads 1 through 3. Upgrades 1 to 2. Writes 3 once a world has changed its effective recharge interval. |
| Client/server protocol | 2. Use the matching mod build on both sides. |
| Optional scripting | KubeJS `2101.7.2-build.381` and Rhino `2101.2.7-build.85` were used to qualify the scripting bridge. |

The [config GUI release](RELEASE-0.5.2.md) explains the Mods list editor. The [0.5.1 beta notes](RELEASE-0.5.1.md) cover the ledger, operator tools, and KubeJS changes.
