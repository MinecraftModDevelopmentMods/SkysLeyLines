# Sky’s Ley Lines 0.5.2.121012 beta

Minecraft 1.21.1, NeoForge 21.1.247 or later in the 21.1 line, Java 21. Install the matching build on client and server.

Open **Mods → Sky’s Ley Lines → Config** to edit new-world defaults. In a local single-player world, use **Server Settings** to choose a Ley Vision preset and set a recharge override. Reopen the world to apply a new recharge interval.

For the ledger, operator tools, and optional KubeJS scripting changes, see the [0.5.1 beta notes](RELEASE-0.5.1.md).
