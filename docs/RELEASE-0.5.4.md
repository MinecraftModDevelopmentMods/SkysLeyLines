# Sky’s Ley Lines 0.5.4.121012 beta

The in-game interface now ships the same 18 locale files as Base Metals for NeoForge 1.21.1. Choose a language in Minecraft’s Language menu to change the dowsing rods, Ley Meter, Config screen, and operator feedback in chat. Item IDs, currency IDs, command syntax, and exact account values stay the same across languages. Dedicated server consoles and RCON use English.

| Language | Locale IDs |
| --- | --- |
| English | `en_au`, `en_ca`, `en_en`, `en_gb`, `en_pt`, `en_us` |
| German | `de_de` |
| Spanish | `es_es`, `es_mx` |
| French | `fr_ca`, `fr_fr` |
| Italian | `it_it` |
| Japanese | `ja_jp` |
| Dutch | `nl_nl` |
| Portuguese (Brazil) | `pt_br` |
| Russian | `ru_ru` |
| Chinese (Simplified, Traditional) | `zh_cn`, `zh_tw` |

This build keeps the [0.5.3 compatibility requirements](RELEASE-0.5.3.md): Minecraft 1.21.1, NeoForge 21.1.247 or later in the 21.1 line, and Java 21. The Java API, ley layout, save schema support, and network protocol are unchanged. Use the same mod build on the server and its clients.
